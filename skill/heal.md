# Heal

1. Confirm the connection dropped using the adapter and real internet probes.
2. Restart the tether once and rerun the full start verification.
3. If it still fails, perform one final restart and rerun the full verification.
4. If the second restart fails, stop and report the exact failed check; do not loop.

Common breaks and fixes:

- **USB/cable or USB mode:** reseat the data cable and restore the official Easy Tether USB mode, then rerun the checks.
- **Driver or adapter:** verify the Easy Tether driver and adapter state with the required Windows permissions, then rerun.
- **Carrier detection/policy:** record the carrier message and test result; contact the carrier or change the plan through the owner, not through an invented software workaround.
