# Stop Tether

1. Request a clean disconnect from the Easy Tether client; check that the client acknowledges or exits cleanly.
2. Confirm the Easy Tether virtual adapter is down; check the OS adapter state rather than trusting the client window.
3. Confirm normal internet is back, or explicitly confirm that no internet is available; run a real probe and report its result.
4. Report the final state and any failed check. Never leave an adapter half-up without saying so.
