# Limits

- **Muse cannot live-test tethering here.** This means Git-FED must run the live checklist on the Windows PC with the phone connected.
- **Tethering needs Windows administration and a virtual network adapter.** This means an elevated local run and a correctly installed Easy Tether driver are prerequisites, not problems Muse can bypass.
- **There is no USB phone or Windows environment in the authoring environment.** This means code review and log diagnosis are possible, but connection proof is not.
- **Carrier blocks, throttling, and plan limits belong to the carrier.** This means software cannot promise service that the mobile plan does not provide.
- **Muse can write, review, and diagnose pasted logs.** This means Git-FED supplies the machine evidence whenever a live failure needs diagnosis.
- **The share layer is closed by default.** This means nobody is admitted and no ports are forwarded until Git-FED explicitly edits the policy files.
