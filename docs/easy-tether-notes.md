# Easy Tether Notes

These notes preserve only the facts supplied in the project search record. Anything not confirmed there is marked unverified.

## Recorded facts

- Easy Tether supports USB tethering.
- The phone-side app does not require root according to the supplied record.
- A desktop client and driver are part of the Windows path.
- Common break points are the driver, the selected USB mode, and carrier detection or carrier policy.
- The supplied record states that Easy Tether has no AI component and that no AI-assisted tethering feature exists yet.

## Unverified here

- Exact current download URLs, version numbers, Windows compatibility matrix, command-line interface, API, service name, adapter name, installer switches, and log locations are unverified in this repository.
- This repository therefore does not invent an Easy Tether CLI or API. The PowerShell launcher uses a configurable executable path and reports when that path has not been supplied.
