# Dark Signal Field

A standalone, dependency-free animated background and local promotional kit for Inter FED NET. Open `index.html` directly or deploy the `animated-background/` folder to GitHub Pages or Cloudflare Pages.

## Pages

- `index.html` — animated landing screen.
- `gallery.html` — comic promo images, banner, logos, sticker, and animated GIFs.
- `about.html` — pipe/operator/share explainer.
- `demo.html` — interactive signal-field demo.
- `404.html` — HTML fallback page for GitHub Pages/Cloudflare Pages.

## Visual details

`favicon.svg` is a symbol mark rather than a letter. The canvas draws orbital signal rings, reactive particles, pointer-driven motion, glow, grain, and reduced-motion support. All navigation and call-to-action buttons resolve to HTML documents, and all asset links are relative so the folder works on both GitHub Pages and Cloudflare Pages.

## FED-OS footer and private communities

Every HTML page includes the animated FED-OS public footer with shortened buttons for the ecosystem, membership landing page, storefront, Whop, contact mailboxes, official media, Patreon, tips, developer Discord, and the public social links requested for navigation. Facebook and the personal Substack are intentionally omitted. The private Matrix destination is not exposed directly in the footer; `private-communities.html` requires an 18+ checkbox and a self-selected eligible country before revealing the provider link.
